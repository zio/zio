# Resources

> Links to source code, API docs, and related projects for ZIO Logging.

## Project

- [Source code and README](https://github.com/zio/zio-logging): the repository, issues, and pull requests.
- [Releases](https://github.com/zio/zio-logging/releases): release notes for each published version.
- [Examples](https://github.com/zio/zio-logging/tree/master/examples): runnable example programs for the modules.
- [API reference (Scaladoc)](https://javadoc.io/doc/dev.zio/zio-logging_3): generated documentation for the public API.

## ZIO

- [ZIO logging](https://zio.dev/reference/observability/logging/): the logging reference on zio.dev.
- [ZIO ecosystem](https://zio.dev/ecosystem/): other ZIO libraries.
- [ZIO Discord](https://discord.gg/zio): chat with the ZIO community.

## Logging backends

- [SLF4J](https://www.slf4j.org/): the Java logging facade used by the SLF4J integrations and bridges.
