LogFormat Reference

LogFormat is a sealed trait that describes how one log line is laid out. You build a format from the values and functions in the LogFormat companion object, join formats with the instance methods, and pass the result to a logger through its configuration. Each part of a format either writes fixed text or reads one part of the log event, such as the level, the message, or an annotation.

The string form of the same DSL, such as %timestamp{...} and %level, is described in Formatting Log Records. This page covers only the Scala API.

Building Blocks​

The companion object provides values and functions that write fixed text or wrap other formats. Each row lists one member of LogFormat.

MemberSignatureDescription
LogFormat.textdef text(value: => String): LogFormatWrites the given string.
LogFormat.spaceval space: LogFormatWrites one space character.
LogFormat.newLineval newLine: LogFormatWrites the platform line separator.
LogFormat.quoteval quote: LogFormatWrites one double quote character.
LogFormat.quoteddef quoted(inner: LogFormat): LogFormatWraps inner in double quotes.
LogFormat.bracketeddef bracketed(inner: LogFormat): LogFormatWraps inner in square brackets.
LogFormat.bracketStartval bracketStart: LogFormatWrites [.
LogFormat.bracketEndval bracketEnd: LogFormatWrites ].
LogFormat.labeldef label(label: => String, value: LogFormat): LogFormatWrites label=value, where value is the output of the inner format.
LogFormat.emptyval empty: LogFormatWrites nothing.

LogFormat.label writes its name as a key, then the inner format as the value. In plain text output the result looks like level=INFO. The JSON output uses the same name as a JSON key.

Composing Formats​

The instance methods join formats together, add styling, or convert a format into a logger. Each method returns a new LogFormat and leaves the original unchanged.

MethodSignatureDescription
+final def +(other: LogFormat): LogFormatJoins two formats with no separator.
LogFormat#concatfinal def concat(other: LogFormat): LogFormatSame as +, with an alphanumeric name.
|-|final def |-|(other: LogFormat): LogFormatJoins two formats with one space between them.
LogFormat#spacedfinal def spaced(other: LogFormat): LogFormatSame as |-|, with an alphanumeric name.
LogFormat#colorfinal def color(color: LogColor): LogFormatWraps the output in the ANSI code for LogFormat#color, followed by the reset code.
LogFormat#highlightfinal def highlight: LogFormatColors the output by log level: ERROR red, WARN yellow, INFO cyan, DEBUG green, and all other levels white.
LogFormat#highlightfinal def highlight(fn: LogLevel => LogColor): LogFormatColors the output with the color that fn returns for the event's level.
LogFormat#fixedfinal def fixed(size: Int): LogFormatCuts the output to size characters, or pads it with spaces up to size. The output becomes plain text.
LogFormat#filterfinal def filter[M >: String](filter: LogFilter[M]): LogFormatWrites the output only when LogFormat#filter accepts the event.
LogFormat#toLoggerfinal def toLogger: ZLogger[String, String]Converts the format into a text logger that returns the formatted line.
LogFormat#toJsonLoggerfinal def toJsonLogger: ZLogger[String, String]Converts the format into a logger that returns one JSON object per event.

The LogFormat#fixed method destroys structure. Use it only for plain text output, because it turns every part of the format into characters.

The LogFormat#color method and the LogFormat#highlight methods add ANSI escape codes. Terminals display them as colors, but log files show the raw codes unless the output goes to a console.

The following example builds a format from the building blocks and a logger name extractor:

import zio.logging.{ LogFormat, LoggerNameExtractor }

val customLine: LogFormat =
  LogFormat.bracketed(LogFormat.level) |-| LoggerNameExtractor.trace.toLogFormat() |-| LogFormat.quoted(LogFormat.line)

The LogFormat#fixed method gives the level a column of seven characters, so lines line up when the level names differ in length:

import zio.logging.LogFormat

val levelColumn: LogFormat = LogFormat.level.fixed(7)

To color only the cause, and to show it only when the event has one, the example combines LogFormat#color and LogFormat#filter:

import zio.logging.{ LogColor, LogFilter, LogFormat }

val errorDetails: LogFormat =
  (LogFormat.space + LogFormat.label("cause", LogFormat.cause).color(LogColor.RED)).filter(LogFilter.causeNonEmpty)

Timestamps​

Two members write the current time at the moment the line is built. The time does not come from the event itself.

MemberSignatureDescription
LogFormat.timestampval timestamp: LogFormatWrites the time in ISO offset date-time format, from DateTimeFormatter.ISO_OFFSET_DATE_TIME.
LogFormat.timestampdef timestamp(formatter: => DateTimeFormatter): LogFormatWrites the time with the given java.time.format.DateTimeFormatter.

The following example writes the time with a custom pattern:

import java.time.format.DateTimeFormatter
import zio.logging.LogFormat

val clockOnly: LogFormat = LogFormat.timestamp(DateTimeFormatter.ofPattern("HH:mm:ss"))

Levels​

Two members write the log level of the event. The level label comes from zio.LogLevel, so the warning level prints as WARN.

MemberSignatureDescription
LogFormat.levelval level: LogFormatWrites the level label, such as INFO.
LogFormat.levelSyslogval levelSyslog: LogFormatWrites the syslog severity number of the level, such as 6 for INFO. FATAL is 2, ERROR is 3, WARN is 4, DEBUG and TRACE are 7.

Logger Name​

Two members write the name of the logger that sent the event. The name comes from an extractor. The extractor members are listed in LogFilter and LogGroup Reference.

MemberSignatureDescription
LogFormat.loggerNamedef loggerName(loggerNameExtractor: LoggerNameExtractor, loggerNameDefault: String = "zio-logger"): LogFormatWrites the name from loggerNameExtractor, or loggerNameDefault when the extractor returns nothing.
LogFormat.enclosingClassval enclosingClass: LogFormatWrites the source file name from the Trace of the log call, or not-available when no trace exists.

LoggerNameExtractor#toLogFormat calls LogFormat.loggerName for you, so you rarely call LogFormat.loggerName with an extractor directly.

Message and Trace​

These members write the message text and the source position of the log call.

MemberSignatureDescription
LogFormat.lineval line: LogFormatWrites the log message.
LogFormat.traceLineval traceLine: LogFormatWrites the line number of the log call, from the Trace. Writes nothing when no trace exists.
LogFormat.fiberIdval fiberId: LogFormatWrites the thread name of the fiber that logged the event.
LogFormat.causeval cause: LogFormatWrites the cause of the event when it is not empty. Writes nothing otherwise.

Use LogFormat.cause with LogFormat#filter and LogFilter.causeNonEmpty when the cause should appear only on failures. The Composing Formats section shows an example.

Spans​

Log spans measure how long a named block of work has run. These members write the elapsed time of each span as a key and value, such as db=12ms.

MemberSignatureDescription
LogFormat.spansval spans: LogFormatWrites every active span in the event.
LogFormat.spandef span(name: String): LogFormatWrites the span with the label name. Writes nothing when no such span exists.

Annotations​

Annotations are key and value pairs that the program attaches to log events. The string annotations come from the event itself. The typed annotations are stored in the logger context, which is described in Logger Context and Annotations.

MemberSignatureDescription
LogFormat.annotationdef annotation(name: String): LogFormatWrites the string annotation with key name, if the event has it.
LogFormat.annotationdef annotation[A](ann: LogAnnotation[A]): LogFormatSame as LogFormat.logAnnotation.
LogFormat.logAnnotationdef logAnnotation[A](ann: LogAnnotation[A]): LogFormatWrites the value of a typed LogAnnotation from the logger context, rendered with the annotation's render method.
LogFormat.anyAnnotationdef anyAnnotation(name: String): LogFormatWrites the string annotation name from the event. When the event lacks it, looks for name in the logger context.
LogFormat.annotationsval annotations: LogFormatWrites every string annotation on the event.
LogFormat.annotationsdef annotations(excludeKeys: Set[String]): LogFormatWrites every string annotation on the event, except the keys in excludeKeys.
LogFormat.logAnnotationsval logAnnotations: LogFormatWrites every typed annotation in the logger context.
LogFormat.logAnnotationsdef logAnnotations(excludeKeys: Set[String]): LogFormatWrites every typed annotation in the logger context, except the keys in excludeKeys.
LogFormat.allAnnotationsval allAnnotations: LogFormatWrites the string annotations on the event and the entries in the logger context.
LogFormat.allAnnotationsdef allAnnotations(excludeKeys: Set[String]): LogFormatSame as LogFormat.allAnnotations, except the keys in excludeKeys are skipped.

The logger name travels as the string annotation whose key is zio.logging.loggerNameAnnotationKey, which holds the value logger_name. To write every annotation except the logger name, pass that key to LogFormat.allAnnotations:

import zio.logging.LogFormat

val withoutLoggerName: LogFormat = LogFormat.allAnnotations(Set(zio.logging.loggerNameAnnotationKey))

Presets and Configuration​

Two presets give ready-made formats. The LogFormat.config value reads a format from a configuration file.

MemberSignatureDescription
LogFormat.defaultval default: LogFormatWrites the timestamp in a 32-character column, the level, the fiber thread name, the quoted message, and the cause when it is not empty.
LogFormat.coloredval colored: LogFormatWrites the same parts as default, with colors on the timestamp, level, thread, and message.
LogFormat.configval config: Config[LogFormat]Reads a format from a string in the configuration file, using the string form described in Formatting Log Records.
LogFormat.parsedef parse(pattern: String): Either[Parser.ParserError[String], Pattern]Parses the string form into a LogFormat.Pattern tree. Most code uses LogFormat.config instead.

The console and file logger configurations read their format key through LogFormat.config. See Configuration Keys Reference for the keys.

Custom Formats With LogFormat.make​

LogFormat.make creates a format from a function. The function receives the parts of the log event and writes into a builder. Only use it when no combinator above fits your output.

Internal builder type

The first argument of the function is a LogAppender. The type is internal to the library, so you cannot name it in your own code, and its methods can change between releases. The builder is an advanced interface for writing a custom backend. Use the combinators on this page for ordinary formats.

The signature of LogFormat.make is:

def make(
  format: (
    LogAppender,
    Trace,
    FiberId,
    LogLevel,
    () => String,
    Cause[Any],
    FiberRefs,
    List[LogSpan],
    Map[String, String]
  ) => Any
): LogFormat

For the string-based way to write output, and for a walkthrough of the builder, see Formatting Log Records.

LogAppender Methods​

A LogAppender writes text, numbers, causes, and key and value pairs to a backend. It is advanced, and it exists to write a custom backend, such as a logging library adapter. The methods below are the operations that the builder exposes to the function given to LogFormat.make. They are not part of the stable public API. For a worked custom format, see Creating a Custom LogFormat.

MethodSignatureDescription
LogAppender#appendTextdef appendText(text: String): UnitWrites unstructured text.
LogAppender#appendNumericdef appendNumeric[A](numeric: A): UnitWrites a number.
LogAppender#appendCausedef appendCause(cause: Cause[Any]): UnitWrites a cause. Backends that know causes can keep their structure.
LogAppender#appendKeyValuedef appendKeyValue(key: String, value: String): UnitWrites one key and value pair.
LogAppender#appendKeyValuedef appendKeyValue(key: String, appendValue: LogAppender => Unit): UnitWrites one key, then lets appendValue write the value.
LogAppender#appendKeyValuesdef appendKeyValues(keyValues: Iterable[(String, String)]): UnitWrites many pairs, with a separator between each pair.
LogAppender#appendKeyValueSeparatordef appendKeyValueSeparator(): UnitWrites the separator between two pairs.
LogAppender#openLogEntrydef openLogEntry(): UnitMarks the start of one log entry.
LogAppender#closeLogEntrydef closeLogEntry(): UnitMarks the end of one log entry.
LogAppender#openKeydef openKey(): UnitMarks the start of a key.
LogAppender#closeKeyOpenValuedef closeKeyOpenValue(): UnitMarks the end of a key and the start of its value.
LogAppender#closeValuedef closeValue(): UnitMarks the end of a value.
LogAppender#withAppendTextfinal def withAppendText(f: (String => Unit) => (String => Unit)): LogAppenderReturns a new appender whose text output passes through f.
