sealed abstract class SecureFtp(unsafeClient: Client) extends FtpAccessors[Client]

Secure Ftp client wrapper

Secure Ftp client wrapper

All ftp methods exposed are lifted into ZIO or ZStream. The underlying java client only provides blocking methods, so each call runs with ZIO.attemptBlockingIO, on ZIO's blocking thread pool, and needs no environment beyond Any.

final case class UnsecureFtpSettings(host: String, port: Int, credentials: PasswordCredentials, binary: Boolean, passiveMode: Boolean, remoteVerificationEnabled: Boolean, proxy: Option[Proxy], sslParams: Option[SslParams], dataTimeout: Option[Duration], defaultTimeout: Option[Duration], keepalive: Option[KeepaliveSettings], controlEncoding: Option[String])

Settings to connect unsecure Ftp server

Settings to connect unsecure Ftp server

Value parameters

binary

specifies the file transfer mode, BINARY or ASCII. Default is ASCII (false)

controlEncoding

character encoding to be used by the FTP control connection, auto-detects UTF-8 if None

credentials

credentials (username and password)

dataTimeout

Sets the timeout to use when reading from the data connection.

defaultTimeout

Sets the default timeout for connections established with these settings, specifically the timeout for the control connection.

host

hostname of ftp server (ipAddress / dnsName)

keepalive

if defined enables TCP keepalive with the provided settings

passiveMode

specifies whether to use passive mode connections. Default is active mode (false)

port

port of communication used by the server

proxy

An optional proxy to use when connecting with these settings

secure

Use FTP over SSL
