# Customize the Generated README

> The `README.md` of a project is generated by `sbt docs/generateReadme` from the introduction in `docs/index.md` and a set of `readme*` settings, so edit those instead of the file. This guide shows how to change a section and how to keep the README up to date.

To replace the title with a banner, set `readmeBanner`. When a banner is set, the `# <projectName>` title is left out unless `readmeShowTitle` says otherwise:

```scala
readmeBanner := "<p align=\"center\"><img src=\"logo.png\" /></p>"
```

To add to a default section instead of replacing it, append to its current value:

```scala
readmeContribution := readmeContribution.value + "\n\nRun `sbt prepare` before you submit a pull request."
```

To fill a section that is empty by default, such as the maintainers, assign a Markdown string:

```scala
readmeMaintainers := "- [A Maintainer](https://github.com/a-maintainer)"
```

An empty string for `readmeAcknowledgement`, `readmeCredits` or `readmeMaintainers` leaves the section out.

To regenerate the README after a change:

```bash
sbt docs/generateReadme
```

To fail a build when the committed README is out of date, run `sbt docs/checkReadme`. The generated CI workflow regenerates the README with the `update-readme` job, which is described in [ZIO SBT CI](../reference/ci.md#default-jobs).

The list of settings and their defaults is in the [ZIO SBT Website reference](../reference/website.md#readme-settings).
