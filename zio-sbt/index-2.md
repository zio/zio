# Reference

> The reference has one page for each module of ZIO SBT. Each page lists the settings, tasks, commands and types of the module, with their types and defaults. For step-by-step instructions, use the How-to Guides instead.

| Page                                          | Module                   | What it covers                                                                          |
| --------------------------------------------- | ------------------------ | --------------------------------------------------------------------------------------- |
| [ZIO SBT Ecosystem](./ecosystem.md)           | `zio-sbt-ecosystem`      | Scala and ZIO version settings, standard settings, the `fmt`, `lint` and `prepare` commands |
| [ZIO SBT Website](./website.md)               | `zio-sbt-website`        | Documentation tasks, website settings, README settings and npm publishing               |
| [ZIO SBT CI](./ci.md)                         | `zio-sbt-ci`             | The generated workflows and every `ci*` setting and task                                |
| [ZIO SBT GitHub Actions](./githubactions.md)  | `zio-sbt-githubactions`  | The model of workflows, jobs, steps and bot configuration                               |
| [ZIO SBT Source](./source.md)                 | `zio-sbt-source`         | `ExprEval`, `SourceFile` and the `mdoc:embed` modifier                                  |
