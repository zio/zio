SqsStreamSettings

zio.sqs.SqsStreamSettings
See theSqsStreamSettings companion object
final case class SqsStreamSettings(attributeNames: List[QueueAttributeName], maxNumberOfMessages: Option[Int], messageAttributeNames: List[String], visibilityTimeout: Option[Int], waitTimeSeconds: Option[Int], autoDelete: Boolean, stopWhenQueueEmpty: Boolean)

Configuration settings for consuming messages from an SQS queue.

Value parameters

attributeNames

List of queue attribute names to retrieve with each message. See AWS SQS API documentation for valid values.

autoDelete

If true, SqsStream.apply deletes the received messages before it emits them. If false, SqsStream.apply does not delete them; delete them with SqsStream.deleteMessage, SqsStream.deleteMessageBatch or SqsStream.deleteMessageBatchSink. SqsStream.consumeChunkAtLeastOnce ignores this setting.

maxNumberOfMessages

Maximum number of messages to retrieve in a single request. Valid values are between 1 and 10.

messageAttributeNames

List of message attribute names to retrieve with each message.

stopWhenQueueEmpty

If true, the stream stops when a receive request returns no messages. If false, the stream keeps polling for new messages.

visibilityTimeout

The duration (in seconds) that the received messages are hidden from subsequent retrieve requests. If None, uses the queue's default visibility timeout. See AWS SQS Visibility Timeout documentation.

waitTimeSeconds

The duration (in seconds) for which the call waits for messages to arrive in the queue before returning. Maximum is 20 seconds. If None, the stream sends no wait time and SQS applies its own default. A value above 0 enables long polling. Short polling increases the number of requests made to SQS and so the cost.
