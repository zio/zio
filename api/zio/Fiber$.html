zio.Fiber

   case Fiber.Status.Done                           => "done"

   case Fiber.Status.Suspended(_, _, FiberId.None)  => "suspended"

sealed abstract class Synthetic[+E, +A]

A synthetic fiber has no fiber of its own on the ZIO runtime: it is created from a pure value or an Exit (Fiber.succeed, Fiber.done), from a future (Fiber.fromFuture), or by combining existing fibers (zip, orElse, map, Fiber.collectAll).

def joinAll[E](fs: Iterable[Fiber[E, Any]])(implicit trace: Trace): IO[E, Unit]

Joins all fibers: awaits every fiber, then succeeds when all of them succeeded, and merges their FiberRef values into the joining fiber. When some fibers fail, it fails with their causes combined in parallel (&&). A fiber that was interrupted adds an "inner interruption" to that cause, which catchAllCause can recover from. When interruptions are the only failures, catchAll cannot recover; when another fiber also failed with a typed error, catchAll catches that error.

def roots(implicit trace: Trace): UIO[Chunk[Runtime[_, _]]]

Returns a chunk containing all root fibers: the fibers that have no parent, such as the main fiber and fibers started with forkDaemon, recorded while the FiberRoots runtime flag is on (as it is by default). Fibers that have ended are removed periodically, so the chunk may still hold some of them. Due to concurrency, the returned chunk is only weakly consistent.
