Queue

zio.Queue
See theQueue companion object
sealed abstract class Queue[A]

A Queue is an asynchronous queue into which values can be enqueued and of which elements can be dequeued. Fibers offer values and take them in the order in which they were offered. take on an empty queue suspends the fiber until a value arrives.

What offer does on a full queue depends on how the queue was made:

  • Queue.bounded suspends the offering fiber until there is room (back pressure).
  • Queue.dropping drops the new value, and offer returns false.
  • Queue.sliding drops the oldest value to make room for the new one.
  • Queue.unbounded has a capacity of Int.MaxValue.

shutdown interrupts the fibers suspended in offer and take. After it, the other operations, except isShutdown, awaitShutdown and shutdown, are interrupted.

val program: UIO[(Int, Chunk[Int])] =
 for {
   queue &lt;- Queue.bounded[Int](2)
   _     &lt;- queue.offerAll(List(1, 2, 3)).fork // waits for room for 3
   first &lt;- queue.take
   rest  &lt;- queue.takeN(2)
 } yield (first, rest)
// succeeds with (1,Chunk(2,3))

def offerAll[A1 <: A](as: Iterable[A1])(implicit trace: Trace): UIO[Chunk[A1]]

Places the values in the queue, in order, and returns the ones that it did not place.

Places the values in the queue, in order, and returns the ones that it did not place.

For Bounded Queue: uses the BackPressure Strategy, places the values in the queue and returns no leftovers. If the queue has reached capacity, then the fiber performing the offerAll will be suspended until there is room in the queue. When that fiber is interrupted, the values already placed stay in the queue.

For Unbounded Queue: Places all values in the queue and returns no leftovers.

For Sliding Queue: uses Sliding Strategy. If there is room in the queue, it places the values, otherwise it removes the oldest elements and enqueues the new ones. Returns no leftovers.

For Dropping Queue: uses Dropping Strategy. It places the values in the queue but if there is no room it will not enqueue them and return the leftovers.

A Hub made with the same strategy behaves the same way. Interrupted when the queue is shut down.

def shutdown(implicit trace: Trace): UIO[Unit]

Shuts down the queue. On a Queue, it interrupts the fibers suspended in offer or take. On a Hub, it shuts down every subscription, which interrupts the fibers suspended in take, and frees the space that the subscriptions held, so publishers suspended by back pressure resume with true. On a hub subscription, it interrupts the fibers suspended in take on that subscription.

Shuts down the queue. On a Queue, it interrupts the fibers suspended in offer or take. On a Hub, it shuts down every subscription, which interrupts the fibers suspended in take, and frees the space that the subscriptions held, so publishers suspended by back pressure resume with true. On a hub subscription, it interrupts the fibers suspended in take on that subscription.

After it, calls to offer*, take*, poll and size are interrupted immediately, while isShutdown, awaitShutdown and shutdown succeed.

def size(implicit trace: Trace): UIO[Int]

Retrieves the size of the queue. For a Queue, this may be negative if fibers are suspended waiting for elements to be added to the queue or greater than the capacity if fibers are suspended waiting to add elements to the queue. For a Hub, it is the number of messages that the hub holds, and for a hub subscription the number of messages waiting to be taken. Interrupted when the queue is shut down.

Takes up to max values from the queue, oldest first. It does not wait: it returns an empty Chunk when the queue is empty or max is 0. With a negative max, it returns an empty Chunk on a Queue and on a subscription to a bounded, dropping or sliding hub, and every waiting message on a subscription to an unbounded hub.
