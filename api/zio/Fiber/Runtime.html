Runtime

zio.Fiber.Runtime
sealed abstract class Runtime[+E, +A]

A fiber that runs an effect on the ZIO runtime, created by forking an effect (ZIO#fork and its variants) or by running one with a Runtime. Runtime fibers have an identity, a status, a trace and their own FiberRef values.

final def interrupt(implicit trace: Trace): UIO[Exit[E, A]]

Interrupts the fiber from whichever fiber is calling this method. If the fiber has already exited, the returned effect will resume immediately. Otherwise, the effect will resume when the fiber exits, after its finalizers have run.

Interrupts the fiber from whichever fiber is calling this method. If the fiber has already exited, the returned effect will resume immediately. Otherwise, the effect will resume when the fiber exits, after its finalizers have run.

The result is the fiber's Exit. When the interruption takes effect, its cause contains an interruption that names the calling fiber, and it can also hold other failures, such as a defect thrown by a finalizer. A fiber that stays uninterruptible until it ends (for example one forked inside ZIO.uninterruptible) returns its own result, which can be a success; so does a fiber that had already ended. An interruption received inside an uninterruptible region takes effect when the region ends, even when that is the fiber's last step.

final def join(implicit trace: Trace): IO[E, A]

Joins the fiber, which suspends the joining fiber until the result of the fiber has been determined. Attempting to join a fiber that has erred will result in a catchable error. Joining an interrupted fiber will result in an "inner interruption" of this fiber, unlike interruption triggered by another fiber, "inner interruption" can be caught and recovered (with catchAllCause, for example).

Joins the fiber, which suspends the joining fiber until the result of the fiber has been determined. Attempting to join a fiber that has erred will result in a catchable error. Joining an interrupted fiber will result in an "inner interruption" of this fiber, unlike interruption triggered by another fiber, "inner interruption" can be caught and recovered (with catchAllCause, for example).

When the fiber succeeds, join also merges the fiber's FiberRef values into the joining fiber (see inheritAll); when it fails, they are not merged.

final def zipWith[E1 >: E, B, C](that: => Fiber[E1, B])(f: (A, B) => C): Synthetic[E1, C]

Zips this fiber with the specified fiber, combining their results using the specified combiner function.

Zips this fiber with the specified fiber, combining their results using the specified combiner function.

Awaiting the returned fiber waits for this fiber and then for that one, even when this one has already failed. When both fail, the causes are combined in parallel (&&). Interrupting the returned fiber sends the interruption to this fiber and then to that one, and then waits for both; their finalizers can run concurrently.

join and inheritAll merge the FiberRef values of that fiber first and of this fiber second. A fiber's value is merged only for the FiberRefs it changed, so for a FiberRef made with the default join function, the value of this fiber wins when both fibers changed it, and the value of that fiber is kept when only that one changed it.

 for {

def await(implicit trace: Trace): UIO[Exit[E, A]]

Awaits the fiber, which suspends the awaiting fiber until the result of the fiber has been determined. The result is the fiber's Exit: a failure, defect or interruption of the fiber comes back as a value, so the returned effect never fails. Unlike join, it does not merge the fiber's FiberRef values into the awaiting fiber.

def inheritAll(implicit trace: Trace): UIO[Unit]

Merges the fiber's current FiberRef values into the calling fiber, using each FiberRef's join function, as join does when the fiber succeeds. It does not wait for the fiber to finish: on a running fiber it takes the values the fiber has at that moment. The fiber's runtime flags are merged too, except for its interruptibility and its wind-down mode.

Merges the fiber's current FiberRef values into the calling fiber, using each FiberRef's join function, as join does when the fiber succeeds. val program: UIO[Int] =
 ZIO.scoped {
   for {
     counter  started.succeed(()) *> ZIO.never).fork
     _       &lt;- started.await
     _       &lt;- fiber.inheritAll
     value   &lt;- counter.get
     _       &lt;- fiber.interrupt
   } yield value
 }
// succeeds with 10
