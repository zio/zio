Config

zio.Config
See theConfig companion trait
object Config

Constructors of Config descriptions: primitives such as int, string, boolean and duration, collections such as listOf, setOf and table, and succeed, fail and defer. Each primitive comes in two forms: without a name it reads the value at the current path (for use inside listOf, table or nested), and with a name it reads the property of that name, like .nested(name).

The object also holds the cases of a description (Primitive, Nested, Zipped, Fallback and the others) that a ConfigProvider inspects to load it, the Error type, and Secret.

sealed trait Error extends Exception, NoStackTrace

The possible ways that loading configuration data may fail.

The possible ways that loading configuration data may fail.

An error is an Exception without a stack trace, and getMessage returns the same text as toString, such as (Missing data at server.port: Expected server.port to be set in properties). && and || combine errors, prefixed adds a path in front of the paths of the errors, and isMissingDataOnly tells whether only data was missing.

val missing: Config.Error = Config.Error.MissingData(Chunk("port"), "Expected port to be set in properties")
val invalid: Config.Error = Config.Error.InvalidData(Chunk("port"), "Expected an integer value")

val bothMissing: Boolean = (missing && missing).isMissingDataOnly
// true
val oneInvalid: Boolean = (missing || invalid).isMissingDataOnly
// false
val message: String = missing.prefixed(Chunk("server")).getMessage
// (Missing data at server.port: Expected port to be set in properties)

final class Secret

A configuration value, such as a password or an API key, whose toString does not show its characters. Two secrets are equal when they hold the same characters in the same order. Config.secret reads a value as a Secret.

A configuration value, such as a password or an API key, whose toString does not show its characters. Two secrets are equal when they hold the same characters in the same order. Config.secret reads a value as a Secret.
