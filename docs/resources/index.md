## Books

- [Zionomicon](https://www.zionomicon.com/) — the comprehensive book on ZIO, by John A. De Goes, Adam Fraser, and Milad Khajavi
- [Effect-Oriented Programming](https://effectorientedprogramming.com/) — building complex applications with ZIO, by Bill Frasure, Bruce Eckel, and James Ward

## Add your own content

Wrote a blog post, gave a talk, built something with ZIO? Don't wait for a docs PR — share it on [Discord](https://discord.gg/2ccFBr4) or [GitHub Discussions](https://github.com/zio/zio/discussions) where the community will actually see it. If it's a library, add it to the [Ecosystem](../ecosystem/index.mdx) page.
