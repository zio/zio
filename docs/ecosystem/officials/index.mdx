Official ZIO libraries are hosted in the [ZIO organization](https://github.com/zio/) on GitHub, and are generally maintained by core contributors to ZIO.

## Development Status

Each project in the ZIO organization namespace has a _Stage Badge_ which indicates the current status of that project:

* **Production Ready** — The project is stable and already used in production. We can expect reliability for the implemented use cases.
* **Development** — The project already has RC or milestone releases, but is still under active development. We should not expect full stability yet.
* **Experimental** — The project is not yet released, but an important part of the work is already done.
* **Research** — The project is at the design stage, with some sketches of work but nothing usable yet.
* **Concept** — The project is just an idea, development hasn't started yet.
* **Deprecated** — The project is not maintained anymore, and we don't recommend its usage.

### Web & APIs

- [ZIO HTTP](https://ziohttp.com) — A type-safe, composable, and feature-rich HTTP library built on top of ZIO.

### Data & Persistence

- [ZIO Cache](/zio-cache/) — A library for optimizing the performance of an application by caching values.
- [ZIO DynamoDB](/zio-dynamodb/) — Simple, type-safe, and efficient access to AWS DynamoDB.
- [ZIO Query](/zio-query/) — A library for writing optimized queries to data sources in a compositional style, with batching, pipelining, and caching.
- [ZIO Quill](/zio-quill/) — A quoted domain-specific language for expressing queries in Scala and executing them as SQL or CQL.
- [ZIO Redis](/zio-redis/) — A type-safe and performant ZIO-native Redis client.
- [ZIO Rocksdb](/zio-rocksdb/) — A ZIO-based interface to RocksDB.

### Messaging & Streaming

- [ZIO AMQP](/zio-amqp/) — A ZIO-based wrapper around the RabbitMQ client with a streaming interface to AMQP queues.
- [ZIO Kafka](/zio-kafka/) — A purely functional, streams-based Kafka client for ZIO.
- [ZIO SQS](/zio-sqs/) — A ZIO-powered client for AWS SQS, built on top of ZIO AWS.
- [ZIO Streams Compress](/zio-streams-compress/) — A library that integrates compression algorithms and archive formats with ZIO Streams.

### Serialization & Schema

- [ZIO Bson](/zio-bson/) — A BSON library with tight ZIO integration and native support for BSON types.
- [ZIO JSON](/zio-json/) — A fast and secure JSON library with tight ZIO integration.
- [ZIO Parser](/zio-parser/) — A library for constructing parsers and pretty printers from invertible syntax descriptions.
- [ZIO Schema](/zio-schema/) — A library for modeling the schema of data structures as first-class values, enabling serialization, deserialization, and data migration.

### Config & Observability

- [ZIO Config](/zio-config/) — A ZIO-based library that extends ZIO's `Config` with support for various sources and automatic derivation.
- [ZIO Logging](/zio-logging/) — Simple logging for ZIO applications, with correlation, context, and pluggable backends.
- [ZIO Metrics Connectors](/zio-metrics-connectors/) — Integrations between ZIO metrics and monitoring systems such as Prometheus and Datadog.
- [ZIO Profiling](/zio-profiling/) — A collection of profilers for understanding the runtime behavior of ZIO programs.
- [ZIO Telemetry](/zio-telemetry/) — Purely functional and type-safe clients for OpenTracing, OpenCensus, and OpenTelemetry.

### Cloud & Infrastructure

- [ZIO AWS](/zio-aws/) — A ZIO wrapper for all AWS services, built on the AWS Java SDK v2.
- [ZIO FTP](/zio-ftp/) — A thin wrapper over (s)FTP clients for ZIO.
- [ZIO Lambda](/zio-lambda/) — A ZIO-based AWS Custom Runtime compatible with GraalVM Native Image.
- [ZIO S3](/zio-s3/) — A thin wrapper over the S3 async client for ZIO.

### Testing & Tooling

- [Izumi Reflect](/izumi-reflect/) — A fast, lightweight, portable and efficient alternative to `TypeTag` from `scala-reflect`.
- [ZIO 2.x Interop Cats 2.x](/zio2-interop-cats2/) — An interoperability layer that lets ZIO 2 work with Cats Effect 2 and its ecosystem.
- [ZIO CLI](/zio-cli/) — A library for rapidly building powerful command-line applications powered by ZIO.
- [ZIO Constraintless](/zio-constraintless/) — A library for building programs as descriptions with maximum polymorphism and modularity, and zero abstraction leakage.
- [ZIO Direct Style](/zio-direct/) — A library for writing ZIO programs in a direct, imperative style, based on the Monadless paradigm.
- [ZIO IntelliJ](https://github.com/zio/zio-intellij) — A plugin for IntelliJ IDEA that brings enhancements when using ZIO in your projects.
- [ZIO Prelude](/zio-prelude/) — A lightweight, distinctly Scala take on functional abstractions, with tight ZIO integration.
- [ZIO Process](/zio-process/) — A library for interacting with external processes and command-line programs, backed by ZIO Streams.
- [ZIO SBT](/zio-sbt/) — A collection of sbt plugins that simplify the development of ZIO projects.
