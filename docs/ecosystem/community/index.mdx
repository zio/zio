In this section we are going to introduce some of the most important libraries that have first-class ZIO support from the community.

If you know a useful library that has first-class ZIO support, please consider [submitting a pull request](https://github.com/zio/zio/pulls) to add it to this list.


## Community Libraries

{/* BEGIN GENERATED: community libraries */}

### Web & APIs

- [Caliban](/ecosystem/community/caliban) — A purely functional library for creating GraphQL servers and clients in Scala.
- [Tapir](/ecosystem/community/tapir) — A library to describe HTTP APIs, expose them as a server, consume them as a client, and document them automatically, with first-class ZIO support.
- [ZIO gRPC](/ecosystem/community/zio-grpc) — A library for writing purely functional gRPC servers and clients with ZIO.

### Data & Persistence

- [Mongo4cats](/ecosystem/community/mongo4cats) — A functional and idiomatic interface for MongoDB, with a dedicated ZIO 2 module.
- [TranzactIO](/ecosystem/community/tranzactio) — A ZIO wrapper for database access libraries, currently Doobie and Anorm.
- [ZIO Apache Parquet](/ecosystem/community/zio-apache-parquet) — A ZIO-powered library for reading and writing Parquet files without running a Spark cluster.
- [ZIO Elasticsearch](/ecosystem/community/zio-elasticsearch) — A type-safe and streaming-friendly ZIO-native Elasticsearch client.
- [ZIO LMDB](/ecosystem/community/zio-lmdb) — An embedded, ACID, key-value database for ZIO, stored in a single file.

### Messaging & Streaming

- [tamer](/ecosystem/community/tamer) — A multi-functional Kafka connector for producing data, based on ZIO Kafka.
- [ZIO Kinesis](/ecosystem/community/zio-kinesis) — A ZIO-based AWS Kinesis client for consuming and producing data.

### Config & Observability

- [LogStage](/ecosystem/community/logstage) — A zero-cost structural logging framework for Scala and Scala.js.
- [Tofu ZIO 2 Logging](/ecosystem/community/tofu-zio2-logging) — Logging integration of Tofu, a functional toolkit based on the tagless-final approach, with ZIO 2.

### Cloud & Infrastructure

- [Scala k8s](/ecosystem/community/scala-k8s) — A Kubernetes client, data models, and typesafe manifest generation for Scala, Scala.js, and Scala Native.
- [ZIO K8s](/ecosystem/community/zio-k8s) — An idiomatic ZIO client for the Kubernetes API, with code generation for custom resources and operators.

### Testing & Tooling

- [Distage](/ecosystem/community/distage) — A compile-time safe, transparent, and debuggable dependency injection framework for pure FP Scala.
- [MUnit ZIO](/ecosystem/community/munit-zio) — An integration library between MUnit and ZIO.
- [Rezilience](/ecosystem/community/rezilience) — A ZIO-native fault tolerance library with policies for making asynchronous systems more resilient to failures.
- [ZIO Test Akka HTTP](/ecosystem/community/zio-test-akka-http) — An Akka HTTP route test kit for ZIO Test.
